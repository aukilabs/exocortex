# Contributing

Every change to any document in your personal exocortex (after setup) should be logged in `CHANGELOG.md`.

If we are editing a file in a loaded repo, make sure to respect the changelog conventions of that repo.

---

## Changelog

Append-only, prepend latest entry on top.

| Field | Description |
|-------|-------------|
| **Timestamp** | When it happened (e.g. `Apr 2, 21:03 HKT, 2026`) |
| **Change** | What changed |
| **Justification** | Why it changed |
| **Author** | Who made the change (human name, or agent name like `Claude`) |

## AGENTS.md

Instructions for how the agent should collaborate with the owner. See the file for details.
